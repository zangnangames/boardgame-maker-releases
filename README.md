# Boardgame Maker

보드게임의 카드·구성품 디자인, 데이터 편집, 인쇄용 파일 만들기를 위한 데스크톱 앱입니다.

## 다운로드

[Windows x64 설치 파일 다운로드 · 0.1.0-beta.1](https://github.com/zangnangames/boardgame-maker-releases/releases/download/v0.1.0-beta.1/Boardgame-Maker-0.1.0-beta.1-windows-x64-setup.exe)

[macOS Apple Silicon · M1 이후](https://github.com/zangnangames/boardgame-maker-releases/releases/download/v0.1.0-beta.1/Boardgame-Maker-0.1.0-beta.1-macos-arm64.dmg)

[macOS Intel](https://github.com/zangnangames/boardgame-maker-releases/releases/download/v0.1.0-beta.1/Boardgame-Maker-0.1.0-beta.1-macos-x64.dmg)

[버전별 다운로드 및 변경 사항](https://github.com/zangnangames/boardgame-maker-releases/releases)

Windows는 `.exe`를 실행해 설치하고 시작 메뉴의 **Boardgame Maker**를 엽니다. Mac은 자신의 칩에 맞는 `.dmg`를 열어 **Boardgame Maker**를 Applications 폴더로 옮깁니다.

현재 버전은 **베타**입니다. Windows 설치 파일은 코드 서명이 없고, Mac 앱은 Apple Developer ID 서명·공증을 받지 않았습니다. 운영체제에서 게시자를 확인할 수 없다는 경고가 나타날 수 있습니다. 내려받은 파일은 각 운영체제의 `SHA256SUMS-*.txt`로 확인할 수 있습니다.

Mac에서 개발자를 확인할 수 없어 차단된다면, 이 저장소에서 받은 파일과 해시가 일치하는지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용할 수 있습니다. [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

프로젝트는 `.bgproj` 파일로 저장합니다. 베타 버전 사용 전 중요한 프로젝트 파일을 별도로 백업하세요. 자동 업데이트는 제공하지 않으며 새 버전은 이 페이지에서 내려받습니다.

이 저장소는 설치 파일과 배포 안내를 제공합니다. 앱 소스 코드는 포함하지 않습니다.

## 포함된 오픈소스

Windows 설치 폴더의 `resources/app/THIRD-PARTY-NOTICES.txt`, Mac 앱 내부의 `Contents/Resources/app/THIRD-PARTY-NOTICES.txt`에 의존성 고지를 포함합니다. 게임 아이콘의 출처·라이선스와 글꼴 라이선스도 앱 리소스에 포함됩니다.
